## Description: <br>
Guides hands-on DOCA Management programming against BlueField / ConnectX devices — standing up management or representor contexts (doca_mgmt_dev_ctx / doca_mgmt_dev_rep_ctx), querying device caps (data-direct, caps-general), toggling congestion-control global status, modifying diagnostics-data, setting ICM quotas, or issuing raw firmware commands via doca_mgmt_raw_cmd with the narrowest correct scope — while routing mlxconfig direct operation, BFB / firmware reflash, streaming telemetry, doca_caps CLI snapshots, and DOCA install to other skills. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and engineers building fleet-management or orchestration tools use this skill to query and safely modify device-level state on BlueField DPUs and ConnectX NICs through the DOCA Management C API, including capability queries, ICM quotas, congestion-control global status, diagnostics data, and scoped raw firmware commands, with hardware-safety gating and debugging of DOCA_ERROR_* results. <br>
