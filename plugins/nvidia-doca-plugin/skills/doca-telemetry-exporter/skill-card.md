## Description: <br>
Guides hands-on DOCA Telemetry Exporter programming on a host where DOCA is installed — defining a doca_telemetry_exporter_schema and event types, creating sources, picking a publish surface (typed events, opaque events, the metrics counter/gauge/histogram API, OTLP logs, or NetFlow), walking the schema-then-source lifecycle, and debugging DOCA_ERROR_* failures from the exporter API. <br>

This skill is ready for commercial/non-commercial use. <br>

NVIDIA <br>

## Use Case: <br>
External developers building applications that emit structured telemetry through DOCA Telemetry Exporter use this skill to define schemas and sources, choose a publish surface, build and run against the shipped C samples, and debug exporter errors when publishing counters, gauges, and events from DOCA-using programs to an external telemetry consumer. <br>
