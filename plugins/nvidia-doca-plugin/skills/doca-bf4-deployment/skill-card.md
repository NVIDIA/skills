## Description: <br>
Guides BlueField-4 (BF4) day-1 platform bring-up from the BMC — installing the BlueField/DOCA bundle ISO onto the DPU (Grace) over UEFI HTTP Boot, PXE, or Redfish Virtual Media, running the PLDM platform-firmware update via the Redfish UpdateService and pldmtool, and installing a Grace Ubuntu image with optional cloud-init — with every irreversible mutating step (PLDM firmware burns, ISO reflashes, power cycles, BMC factory resets) governed by doca-hardware-safety. <br>

This skill is ready for commercial/non-commercial use. <br>
