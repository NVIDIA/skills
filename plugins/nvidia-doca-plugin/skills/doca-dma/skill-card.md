## Description: <br>
Guides hands-on DOCA DMA programming — bringing up a doca_dma context, configuring the doca_dma_task_memcpy task, sizing buffers via doca_dma_cap_task_memcpy_* queries, setting source/destination doca_mmap permissions (including doca_mmap_export_* for cross-peer copies), driving the progress engine, and debugging DOCA_ERROR_* returns. <br>

This skill is ready for commercial/non-commercial use. <br>

NVIDIA <br>

## Use Case: <br>
External developers building C/C++ (or FFI-bound) applications on BlueField DPUs or ConnectX NICs use this skill to offload memory copies to the DOCA DMA engine, choose between DMA and adjacent libraries (RDMA, Comch, CPU memcpy), and debug DMA errors. <br>
