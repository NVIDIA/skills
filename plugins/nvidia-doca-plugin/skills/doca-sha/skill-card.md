## Description: <br>
Guides agents through SHA-1, SHA-256, and SHA-512 digest acceleration on BlueField-2 silicon via the DOCA SHA library (absent on BlueField-3), covering one-shot `doca_sha_task_hash` versus incremental `doca_sha_task_partial_hash`, `doca_sha_cap_*` capability and buffer-size queries, mmap permissions, and decoding `DOCA_ERROR_*` statuses. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External developers building C/C++ (or FFI-bound) applications that consume the DOCA SHA library use this skill to configure, build, modify, run, test, and debug SHA hash offload on a BlueField-2 DPU with DOCA already installed. <br>
