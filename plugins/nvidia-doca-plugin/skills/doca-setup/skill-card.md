## Description: <br>
Guides the agent through the DOCA environment around a workload — verifying an install is healthy, preparing the build environment (pkg-config, headers, LD_LIBRARY_PATH, hugepages, devlink, representors), debugging env-class failures, deciding container-vs-bare-metal deployment shape, or reaching a DOCA install from a host without one via the NGC DOCA container Stage-1 fallback. <br>

This skill is ready for commercial/non-commercial use. <br>
