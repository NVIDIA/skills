## [Unreleased] - NVIDIA Verified Plugins

### Added

- **NVIDIA Verified Plugins**: curated, product-owned plugin bundles maintained in each product team's repo and mirrored into this catalog, each signed, verified, evaluated with signed results in `BENCHMARK.md`, and described by a Plugin Card:
  - TAO Toolkit (`nvidia-tao-toolkit`) — train, fine-tune, optimize, and export vision AI models
  - DOCA (`nvidia-doca-plugin`) — DOCA SDK development on BlueField DPUs and ConnectX NICs, with a local MCP server
  - NVIDIA FLARE (`nvidia-nvflare`) — build, convert, simulate, and debug federated learning jobs
  - BioNeMo (`nvidia-bionemo`) — biomolecular and genomics workflows across BioNeMo models, libraries, and NIMs
- Plugins available on build.nvidia.com and through the `nvidia-official` marketplace for Claude Code, Codex, and Cursor, and listed for OpenClaw (ClawHub) and Hermes
- Plugin Catalog in [`README.md`](README.md), regenerated by the plugin sync
- "Verifying Plugins" section in [`README.md`](README.md) covering plugin signatures, Plugin Cards, and signed evaluation results

### Changed

- [`README.md`](README.md) now covers skills and plugins: retitled to "NVIDIA Agent Skills and Plugins", a single Quickstart table with Skills and Plugins columns for each agent, and plugin coverage in Getting Help, Repository Structure, Roadmap, and Standards & Compatibility
- The `nvidia-skills` discovery plugin recommends Verified Plugins first
