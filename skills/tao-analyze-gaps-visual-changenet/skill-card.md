## Description: <br>
Performs gap analysis on NVIDIA TAO VCN Classify (Visual Component Net) experiments by invoking the pinned TAO data-services container directly via `docker run … gap_analysis vcn_aoi …` — picks the optimal decision threshold, ranks per-sample weakness, and emits a top-K weakest parquet expanded per-lighting for downstream augmentation. <br>

This skill is ready for commercial/non-commercial use. <br>

NVIDIA <br>

## Use Case: <br>
Developers and ML engineers use this skill to analyze NVIDIA TAO VCN Classify inference failures, choose a recall-constrained decision threshold, pick synthetic-data augmentation targets, and audit PASS/NO_PASS boundary cases, producing a gap-analysis report with spot-checked weak samples. <br>
