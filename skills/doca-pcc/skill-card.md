## Description: <br>
Guides hands-on host-side DOCA PCC work to load a custom Programmable Congestion Control algorithm onto a BlueField DPU — creating per-port `doca_pcc` contexts, loading a `dpacc`-compiled `doca_pcc_app` onto the `doca_dev` for the RoCE-bearing port, parameterizing it, walking triple-axis capability discovery (DOCA cap-query, DPA-capable BlueField, firmware custom-PCC slot enabled), and debugging `DOCA_ERROR_*` from `doca_pcc_*` calls. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External developers consuming the DOCA PCC host-side C library use this skill to load a custom, dpacc-built congestion control algorithm onto a BlueField DPU port carrying RDMA/RoCE traffic, check which PCC features their DOCA install, BlueField generation, and firmware expose, and debug DOCA_ERROR_* failures from doca_pcc_* calls. <br>
