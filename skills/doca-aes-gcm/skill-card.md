## Description: <br>
Guides agents through hands-on DOCA AES-GCM work on a BlueField DPU or ConnectX NIC — configuring encrypt/decrypt tasks, querying key-type (128/256-bit only) and task capabilities, sizing buffers, setting mmap permissions, validating against published NIST GCMVS or RFC 5288 vectors, and debugging DOCA_ERROR_* outcomes, including treating decrypt tag-verification failure as a security event. <br>

This skill is ready for commercial/non-commercial use. <br>

External developers building C/C++ (or FFI-bound) applications that consume the DOCA AES-GCM library use this skill to offload AES-GCM authenticated encryption and decryption to BlueField DPU or ConnectX accelerators, covering configure, build, modify, run, test, and debug workflows. <br>
