## Description: <br>
Guides hands-on DOCA Management programming against BlueField / ConnectX devices: standing up management or representor contexts (doca_mgmt_dev_ctx / doca_mgmt_dev_rep_ctx), querying device caps (data-direct, caps-general), toggling congestion-control global status, modifying diagnostics-data, setting ICM quotas, or issuing raw firmware commands via doca_mgmt_raw_cmd with the correct scope, while routing mlxconfig, BFB / firmware reflash, streaming telemetry, doca_caps CLI snapshots, and DOCA install to other skills. <br>

This skill is ready for commercial/non-commercial use. <br>

Developers and engineers building fleet-management or orchestration tools on hosts with BlueField DPUs or ConnectX NICs use this skill to query and safely modify device-level state through the DOCA Management C API, including capability gating, raw-command scope selection, DOCA_ERROR_* debugging, and hardware-safety rollback discipline. <br>
