## Description: <br>
Use this skill when the user is building or interpreting the doca/tools/gpunetio_ib_write_bw tool pair — a CUDA kernel posts RDMA WRITE work requests through the doca-gpunetio device-side surface to measure sustained GPU-driven WRITE bandwidth on a GPU + IB-device pair. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External developers and performance engineers use this skill to build, run, and interpret the gpunetio_ib_write_bw client/server benchmark so they can produce a reproducible measurement of sustained kernel-initiated RDMA WRITE bandwidth on their own GPU-NIC pair and decide whether the GPUNetIO path is the right runtime surface for a workload class. <br>
