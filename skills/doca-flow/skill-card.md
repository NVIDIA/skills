## Description: <br>
Guides agents through DOCA Flow hardware packet steering on NVIDIA NICs/DPUs from a C application — match/action pipes, ports, representors, forwarding, hairpin, counters, connection tracking, pipe validation, version matching, and Flow API error debugging — starting from the NGC DOCA container and shipped DOCA Flow samples rather than authored code. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and engineers building applications on the DOCA Flow library use this skill to bring up Flow ports and representors, design and validate match/action pipes, program entries, read hardware counters, add connection tracking, and debug DOCA Flow build and runtime errors on a supported NVIDIA NIC/DPU with DOCA installed. <br>
