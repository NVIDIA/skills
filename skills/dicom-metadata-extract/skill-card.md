## Description: <br>
Used for extracting selected metadata from one DICOM file and flagging standard-tag PHI presence. Not for anonymization or clinical use. <br>

This skill is for research and development only. <br>

## Owner
NVIDIA <br>

## Use Case: <br>
Developers and engineers use this skill at engineering time to extract literal header metadata (transfer syntax, modality, study/series/image fields) from a single DICOM file as JSON and to flag whether a small subset of standard PHI tags is populated. It is not a de-identifier and is not for clinical deployment, regulatory de-identification, autonomous diagnosis, or patient-facing use. <br>
