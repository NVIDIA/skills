## Description: <br>
Guides wiring the DOCA SHA Offload Engine (an OpenSSL ENGINE) into an existing OpenSSL pipeline to offload one-shot SHA-1, SHA-256, or SHA-512 (EVP_Digest) onto DOCA SHA hardware without rewriting against doca-sha, covering engine load mechanics, the SHA-224 negative test that proves offload engaged, the message-size window where offload beats CPU SHA, and engine-vs-library selection. <br>

This skill is ready for commercial/non-commercial use. <br>

NVIDIA <br>

## Use Case: <br>
Developers and engineers with an existing OpenSSL-based application on a BlueField-2 DOCA host use this skill to load the DOCA SHA Offload Engine, verify that SHA digests are actually offloaded rather than falling back to software, measure when offload outperforms CPU SHA, and decide between the engine and the doca-sha library. <br>
