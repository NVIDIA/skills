## Description: <br>
Guides an agent through driving the DOCA ngauge tool to analyze, visualize, and debug single-node network performance by probing NIC hardware counters on BlueField-3 or ConnectX-7 and above and storing collected data in HDF5 format, covering YAML configuration, execution, HDF5 parsing and plotting, and fwctl conflict diagnosis while routing install, version, and hardware/firmware state changes to other skills. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, network and performance engineers, and AI agents use this skill to configure and run DOCA ngauge on a host or BlueField Arm, sample NIC hardware counters into HDF5 output, plot the collected data with the sample plugins, and diagnose fwctl driver conflicts or missing prerequisites. <br>
