## Description: <br>
Guides safe DOCA version changes — upgrading or downgrading host packages, refreshing the BlueField BFB, bumping the NGC DOCA container tag, or rolling back — with a strict detect → report → ask → guided-upgrade discipline that never upgrades automatically. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and engineers working with NVIDIA DOCA use this skill to detect version gaps and safely plan, execute, verify, or recover upgrades, downgrades, and rollbacks of DOCA across host packages, BlueField BFBs, and NGC containers. <br>
