## Description: <br>
Use this skill when operating the DOCA Firefly Service container on BlueField — choosing the four PTP configuration axes (role / profile / domain / interface), wiring the BlueField PHC plus host follower and consumer-workload pairing, deciding whether PTP-grade time is needed versus chrony / NTP, or debugging a Firefly deployment where PTP is not syncing or the host clock is not following. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External operators and platform teams who deploy the DOCA Firefly Service container on BlueField Arm use this skill to provide PTP-grade time synchronization to time-sensitive workloads — selecting the PTP role / profile / domain / interface, wiring the host-side time follower to the BlueField PHC, pairing with consumer workloads such as Rivermax SMPTE, 5G UPF, finance, or distributed databases, and debugging deployments where PTP is not syncing or the host clock is not following. <br>
