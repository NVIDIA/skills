## Description: <br>
Run AnomalyGenNext 1.1 inference from a native testcase or a prepared generation plan, then publish validated fine-grained and binary COCO labels for synthetic object-detection defect generation (not model training). <br>

This skill is ready for commercial/non-commercial use. <br>

## Owner
NVIDIA <br>

### License/Terms of Use: <br>
Apache 2.0 <br>
## Use Case: <br>
Developers and engineers use this skill to generate synthetic object-detection defect images with the pinned AnomalyGenNext 1.1 container from an existing task checkpoint and recipe, and to publish validated native and binary COCO pseudo-labels for downstream detector workflows. <br>
