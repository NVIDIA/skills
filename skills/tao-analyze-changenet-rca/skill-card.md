## Description: <br>
Performs deep Root Cause Analysis (RCA) on NVIDIA TAO Visual ChangeNet classification experiments with image-evidence-driven investigation, for analyzing ChangeNet model failures, investigating poor recall / FAR / PASS-NO_PASS metrics, auditing visual inspection pipeline quality, or producing an RCA report for an AOI defect-detection model. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and ML engineers working on NVIDIA TAO Visual ChangeNet AOI defect-detection models use this skill to run a five-phase, image-evidence-driven root cause analysis over an experiment's training and inference results and produce an RCA report with ranked root causes, counterfactual impact estimates, and recommended fixes. <br>
