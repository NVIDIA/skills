Build and verify an NVIDIA PVA operator with the public PVA SDK, running optional EMU correctness, a fresh L4T build, direct-SSH Tegra hardware correctness, and optional hardware performance to return PASSED, FAILED, or BLOCKED with exact evidence. <br>

This skill is ready for commercial/non-commercial use. <br>
