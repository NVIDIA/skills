## Description: <br>
Use this skill when the user is doing hands-on DOCA Telemetry Exporter programming on a host where DOCA is installed — defining a doca_telemetry_exporter_schema and event types, creating sources, picking a publish surface (typed events / opaque events / the metrics counter-gauge-histogram API / OTLP logs / NetFlow), walking the schema-then-source lifecycle, or debugging DOCA_ERROR_* failures from the exporter API. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External developers and engineers building DOCA-using applications on BlueField DPUs and ConnectX NICs use this skill for hands-on guidance on publishing structured telemetry (counters, gauges, histograms, events, OTLP logs, NetFlow records) through DOCA Telemetry Exporter, covering the schema-then-source lifecycle, publish-surface selection, transport introspection, and DOCA_ERROR_* diagnosis. <br>
