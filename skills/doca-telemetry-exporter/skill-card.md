## Description: <br>
Hands-on DOCA Telemetry Exporter programming on a host with DOCA installed: defining doca_telemetry_exporter schemas and event types, creating sources, choosing a publish surface (typed events, opaque events, the counter/gauge/histogram Metrics API, OTLP logs, or NetFlow), following the schema-then-source lifecycle, and debugging DOCA_ERROR_* failures from the exporter API. <br>

This skill is ready for commercial/non-commercial use. <br>

## Owner
NVIDIA <br>

## Use Case: <br>
External developers and engineers writing applications that call the doca_telemetry_exporter_* API (in C/C++ or via FFI/bindings) to publish structured telemetry — counters, gauges, histograms, events, OTLP logs, or NetFlow records — from a DOCA-using program to an external consumer such as the DOCA Telemetry Service, including configuring, building, modifying shipped samples, testing transport liveness, and debugging exporter errors. <br>
