## Description: <br>
Use this skill when the user is doing hands-on DOCA SHA programming — offloading SHA-1, SHA-256, or SHA-512 hashing onto a BlueField DPU or ConnectX accelerator, picking between one-shot doca_sha_task_hash and incremental doca_sha_task_partial_hash, querying doca_sha_cap_* for algorithm support and buffer sizes, setting source/destination doca_mmap permissions, or decoding DOCA_ERROR_* returns from the SHA API. <br>

This skill is ready for commercial/non-commercial use. <br>
