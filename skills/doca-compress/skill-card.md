## Description: <br>
Provides agent guidance for hardware compression offload with DOCA Compress on a BlueField DPU, ConnectX NIC, or host — DEFLATE compress and decompress plus LZ4 stream/block decompress — covering task enablement on a doca_compress context, source/destination doca_buf sizing against per-task capability queries, mmap permissions, offload-vs-CPU decisions, round-trip validation, and DOCA_ERROR_* diagnosis. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External developers and engineers building applications that call the DOCA Compress library (in C/C++ or through FFI bindings) use this skill to configure, build, test, and debug bulk DEFLATE compression and DEFLATE/LZ4 decompression offload on BlueField DPUs and ConnectX NICs, and to decide when offload beats CPU compression. <br>
