## Description: <br>
PointPillars for 3D object detection from LiDAR point clouds, encoding point clouds into a pseudo-image via pillar-based representation then applying 2D detection for autonomous driving and robotics. <br>

This skill is ready for commercial/non-commercial use. <br>
