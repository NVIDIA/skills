## Description: <br>
Guides an agent driving the DOCA Pipeline Language (DPL) Developer Tools to inspect or debug DPL programs on a BlueField DPU — DPL Nspect for runtime state such as tables, keys, and counters, DPL Debugger for packet flow, DPL Admin for dynamic configuration changes in the DPL Runtime Daemon, P4 Runtime Shell as a P4Runtime control plane manager, or DPL Runtime Controller SDK for custom P4Runtime applications and DPL shared memory APIs — while routing DPL program authoring/compiling/deploying, DOCA install/bring-up, and hardware or firmware state changes to their owning skills or guides. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and engineers working with DOCA Pipeline Language programs on NVIDIA BlueField DPUs use this skill to have an agent inspect DPL runtime state, debug packet flow, dynamically change dpl_rtd configuration items, use the P4 Runtime Shell, or build custom P4Runtime applications with the DPL Runtime Controller SDK, with prerequisite checks (DPL Runtime Service container running, dpl_rtd active, DPU mode, debug flag -g) before acting. <br>
