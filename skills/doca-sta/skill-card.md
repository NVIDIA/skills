## Description: <br>
Guides hands-on DOCA STA (Storage Target Acceleration) work on BlueField — instantiating doca_sta, declaring doca_sta_subsystem NQNs and namespaces over local NVMe disks via doca_sta_be, validating platform support with doca_sta_cap_is_supported, sizing I/O queues via the doca_sta_get_max_* queries, and decoding DOCA_ERROR_* statuses such as IO_FAILED, while routing raw RDMA movement, packet I/O, steering rules, initiator-side NVMe, and SDK install to other skills. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External developers and engineers building NVMe-over-Fabrics storage targets in C/C++ (or FFI-bound languages) on DOCA STA use this skill to configure, modify, build, run, test, and debug target-side NVMe-oF acceleration over RDMA on BlueField, presenting subsystems backed by local NVMe-PCI disks to remote initiators. <br>
