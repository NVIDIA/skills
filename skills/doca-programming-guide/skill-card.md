## Description: <br>
Guides developers writing their first DOCA application or asking library-agnostic DOCA programming questions — picking a shipped sample to copy and modify, wiring pkg-config + meson (or FFI from Rust / Go / Python against the public C ABI), walking the DOCA Core lifecycle (create → configure → start → connect → use → stop → destroy), and decoding DOCA_ERROR_* codes. <br>

This skill is ready for commercial/non-commercial use. <br>

## Owner
NVIDIA <br>

## Use Case: <br>
External developers and engineers building applications that consume NVIDIA DOCA libraries (in C/C++ directly or via FFI/bindings) use this skill to derive a first app from a shipped sample, build it with the canonical pkg-config pattern, follow the DOCA Core object lifecycle, and debug DOCA_ERROR_* results and program-class failures. <br>
