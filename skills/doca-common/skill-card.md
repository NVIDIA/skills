## Description: <br>
Provides agent guidance for the foundational DOCA Core primitives — the doca_ctx lifecycle, doca_dev/doca_devinfo discovery and capability gating, doca_mmap/doca_buf_inventory/doca_buf zero-copy buffers, the doca_pe progress engine, and the two-tier DOCA Log model — that every per-library DOCA context relies on. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External developers and engineers building applications that consume any DOCA library use this skill to set up the universal DOCA foundation — device discovery, context lifecycle, zero-copy buffers, the progress engine, and logging — before and alongside per-library work on BlueField DPUs and ConnectX NICs. <br>
