## Description: <br>
Guides agents through hands-on DOCA GPI programming — wiring a GPU-Packet-Initiator context so a CUDA kernel drives RDMA queues directly from GPU memory without host CPU mediation — covering GPI vs doca-gpunetio selection, the doca_gpi / domain / channel object model, the GPU-side doca_gpu_gpi_channel* handle handoff, attaching GPU memory to a GPI domain, domain and channel attribute sizing, and debugging DOCA_ERROR_* from doca_gpi_* calls. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External developers and engineers building GPU-resident DOCA applications use this skill to create and configure GPI domains and channels, hand the GPU-side channel handle to a CUDA kernel, connect endpoints to a remote peer, attach memory regions, and debug doca_gpi_* errors on a host with a BlueField/ConnectX device, an NVIDIA GPU, and DOCA installed. <br>
