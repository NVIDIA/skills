## Description: <br>
RDMA data movement on NVIDIA BlueField/ConnectX NICs (RoCE/InfiniBand) with DOCA RDMA instead of hand-written libibverbs/rdma_cm, covering RDMA context bring-up on a doca_dev, connection methods (RDMA CM, bridge/OOB, or gRPC exchange of doca_rdma_export()), the eleven task types, matching mmap and RDMA permissions, queue and connection sizing, doca_rdma_cap_* queries, and DOCA_ERROR_* from RDMA calls. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
External developers and engineers building applications that consume the DOCA RDMA library — code that calls doca_rdma_* (in C/C++ or through a thin FFI/cgo shim) to move data between processes or hosts over the NIC. They use this skill to build and extend the shipped DOCA RDMA samples, pick connection methods and task types, set correct mmap permissions, check device capabilities, and debug RDMA errors without falling back to raw libibverbs. <br>
