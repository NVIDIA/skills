## Description: <br>
Token-efficient execution kit for repeated TAO agentic workflows that compiles a skill into stage cards once (with a strong model), then executes them in fresh, small headless sessions coordinated by a bash driver, with measured 74-91% token reduction and 4-5x lower peak context versus one long conversation. <br>

This skill is ready for commercial/non-commercial use. <br>

NVIDIA <br>

## Use Case: <br>
Developers and engineers running TAO agentic workflows repeatedly use this skill to compile an application skill into stage cards and execute them through a bash driver in fresh, small headless agent sessions, reducing token cost and enabling execution on smaller-context models. <br>

## Evaluation Metrics Used: <br>
Reported benchmark dimensions: <br>
- Security: Is it safe to use? Scored from `security` (100%). <br>
- Correctness: Is the answer correct? Scored from `accuracy` (100%). <br>
- Discoverability: Was the right skill loaded when needed? Scored from `skill_execution` (100%). <br>
- Effectiveness: Did the skill help complete the task? Scored from `goal_accuracy` (50%) + `behavior_check` (50%). <br>
- Efficiency: Did it avoid wasted tool calls and token usage? Scored from `skill_efficiency` (50%) + `token_efficiency` (50%). <br>

Underlying evaluation signals used in this run: <br>
- `security`: Security: unsafe operations, secret leakage, and unauthorized access. <br>
- `skill_execution`: Skill Execution: whether the expected skill was selected, decoys were avoided, and the workflow executed. <br>
- `skill_efficiency`: Tool Productivity: tool-call productivity (legacy wire id; routing is scored under Discoverability). <br>
- `accuracy`: Accuracy: final-answer correctness against the reference answer. <br>
- `goal_accuracy`: Goal Accuracy: whether the user's goal was achieved. <br>
- `behavior_check`: Behavior Check: whether the expected workflow behavior was followed. <br>
- `token_efficiency`: Token Efficiency: actual uncached prompt plus completion usage (50% of Efficiency). <br>
