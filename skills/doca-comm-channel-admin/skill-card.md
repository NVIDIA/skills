## Description: <br>
Use this skill to enumerate host↔DPU DOCA comch (formerly Comm Channel) servers and connections via the shipped doca_comm_channel_admin binary — a single-shot, read-only scan-and-print tool that lists comch-capable devices and decodes the per-device server / connection table (server name, PID, in-use / max, PCIe address), while routing channel reset / drain / restart, the comch programming API, and library install to other DOCA skills. <br>

This skill is ready for commercial/non-commercial use. <br>

## Owner
NVIDIA <br>

## Use Case: <br>
Platform operators, developers of DOCA Comch consumers, and AI agents use this skill to run the DOCA Comm Channel Admin Tool on a host or BlueField Arm side and read its SERVERS and CONNECTIONS tables, inventorying host↔DPU comch channels from outside the program and cross-checking the admin tool's view against program-side connection state before recommending code or lifecycle changes. <br>
