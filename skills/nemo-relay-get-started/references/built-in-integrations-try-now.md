# Framework Trial Routing

Use the maintained integration when the framework owns execution. Read the
matching current quick start:

- [LangChain](https://docs.nvidia.com/nemo/relay/getting-started/quick-start/langchain)
- [LangGraph](https://docs.nvidia.com/nemo/relay/getting-started/quick-start/langgraph)
- [Deep Agents](https://docs.nvidia.com/nemo/relay/getting-started/quick-start/deep-agents)

Derive extras, provider dependencies, attachment APIs, sample files, plugin
activation, and verification from the selected guide compatible with the
installed release. Do not keep a copy of callback wiring, model choices, or
expected markers in this reference.

Preserve the existing project and package manager. Use the maintained sample
for a standalone trial, or adapt its smallest documented attachment to an
existing safe workflow. Do not replace framework scheduling, retries, or
internals to manufacture the demonstration.

Check whether this particular guide uses local deterministic execution or a
live provider. Require only its documented credentials and lifecycle evidence;
a graph/node proof need not include a managed tool or model call.

Follow [Guide-Based First-Value Checks](first-value.md). Use broader
instrumentation only for application-owned calls outside maintained coverage.
