## Description: <br>
Guides developers adding DOCA capabilities — most commonly DOCA Flow hardware steering — to an existing DPDK application in-place via the DOCA DPDK Bridge, covering DPDK port binding to a `doca_dev` (`doca_dpdk_port_probe` / `doca_dpdk_port_as_dev`), `rte_mbuf` ↔ `doca_buf` conversion, `doca_dpdk_cap_is_rep_port_supported` capability queries, and debugging `DOCA_ERROR_*` returned from bridge calls. <br>

This skill is ready for commercial/non-commercial use. <br>

NVIDIA <br>

## Use Case: <br>
External developers who already maintain a DPDK-based packet-processing application use this skill to add DOCA capabilities (most commonly DOCA Flow hardware steering) in-place by linking the DOCA DPDK Bridge, including configuring, building, modifying, running, testing, and debugging the bridge integration on a host with DOCA and DPDK installed. <br>
